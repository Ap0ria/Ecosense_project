# EcoSense Project Statement

## Aim
Build a small Python application that helps a user classify everyday waste and keep a record of waste entries.

## Core workflow
User → item details → validation → classification → status → recommendation → WasteItem → CSV storage → history/search/statistics.

## Supported materials
plastic, paper, glass, metal, organic, e-waste

## Conditions
clean, dirty, damaged

## Main menu
1. Classify Waste
2. View Waste History
3. Search Records
4. View Statistics
5. View Recycling Recommendations
6. Exit
